# Hawk 1.1.0

Hawk is the new name for Squint. It now has the Sedge look shared by every webhookstudios app: one set of colors, fonts and icons, in light and dark mode.

- New icon, colors and fonts. Window titles and headings use the Sedge serif.
- Buttons and menus use sentence case, like the rest of the suite.
- The camera preview background matches the Sedge palette.
- Everything works exactly as before. Your settings and presets carry over.

Install:

```bash
sudo apt install ./squint_1.1.0_all.deb
```
